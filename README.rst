Library for machine learning on physical tensors

Tensorial is an open-source Python library for machine learning on physical tensors.
It combines JAX-based numerical tooling with geometric and equivariant model components
for scientific ML, with a focus on atomistic and materials applications.

The project is built for tensor-valued representations and symmetry-aware learning, making it
useful for tasks such as molecular and materials modeling, graph-based neural networks, and
other physics-informed machine learning workflows.
