Contributing
============

Contributions are welcome.

This project is intended to remain open source forever. We use the GNU Affero General Public License v3 or later (AGPLv3+) for that purpose, and contributors should be aware that their contributions will be incorporated into software that is distributed under that license.

Please make sure you are comfortable contributing under AGPLv3 before submitting work. If you are contributing code on behalf of an employer or organization, please confirm that the relevant rights are in place for the contribution to be included in an AGPLv3 project.
